## Repository Structure
- `setup/`: OpenFOAM case setups, boundary conditions (`0.orig/`), physical properties, and solver dictionaries.
- `scripts/`: Meshing utilities, NACA coordinate generators, GCI / Richardson extrapolation calculators, and plotting scripts.
- `data/`: Experimental benchmark data (NASA TMR) alongside extracted CFD result tables.
- `figures/`: Generated figures (mesh diagnostics, convergence histories, $C_p$ distributions, GCI plots).
